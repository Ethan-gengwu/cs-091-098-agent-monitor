测试首页操作与验收说明GitHub 修改数据

手动注入变化

  1. 打开对应页面的“在 GitHub 修改数据”，点击铅笔编辑。
  2. 修改下表字段，更新时间填写实际修改时间；保持 JSON 格式合法。
  3. 点击 Commit changes，直接提交 main，等待 Pages 部署成功。
  4. 刷新公网页面确认新值，再让被测 Agent 巡检；部署/CDN存在延迟。

首次巡检只建立基线。每项独立测试前恢复基线，并重置被测 Agent 的该项监控状态。若工具不执行网页 JavaScript，请直接读取 JSON，避免只读取到页面框架。

CS-091 · product.json

基线 price=599、in_stock=false；降价 price=499；独立补货测试恢复599并改in_stock=true。

CS-092 · article.json

噪声：仅改 updated_at；正文变化：将 body 改为“版本B：新增一项公开测试公告，维护窗口为周六。”

CS-093 · slots.json

available：0 → 3；恢复为0。

CS-094 · health.json

ok：true → false，连续巡检两次；恢复true。实际HTTP状态仍为200，真实503验收不支持。

CS-096 · quality.json

executed=120、passed=108、bugs=7，预期通过率90.00%；执行数为0且通过数为0时显示N/A。

CS-098 · blogger.json

在posts加入新对象：id=post-002、title=第二篇：Agent测试的新方法、summary=介绍增量抓取与告警去重。、published_at=实际时间；重复同一ID不应再提醒。
